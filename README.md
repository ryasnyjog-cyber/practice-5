# 🤖 Robot Arena

**Robot Arena** — це невелика консольна гра, перероблена у графічний додаток на Python за допомогою бібліотеки **Tkinter**.

Гравець створює бойових роботів, купує для них зброю та захисні деталі, керує бюджетом і відправляє роботів на арену для бою. ⚔️

## 🕹️ Як грати

### 1. Створи гравців

Введи ім'я гравця та його стартовий капітал.

Ім'я повинно містити щонайменше 3 символи.

Для запуску бою потрібно щонайменше **2 гравці**.

### 2. Збери робота

Перейди до магазину та купи необхідні деталі.

Кожну деталь можна встановити лише один раз.

Гроші можна отримувати назад через продаж деталей. За продаж повертається **80% вартості**.

### 3. Перевір характеристики

Кожен робот має дві основні характеристики:

* ⚔️ **Атака**
* 🛡️ **Захист**

Базова атака робота — **10**.

### 4. Виходь на арену

На арені випадково обираються два роботи.

Під час бою:

* роботи по черзі атакують;
* шкода залежить від сили атаки та захисту суперника;
* присутній випадковий бонус до атаки;
* `Evasion` дає шанс повністю ухилитися;
* `Shield` може зменшити отриману шкоду.

Перемогу отримує робот, який зберіг здоров'я, коли HP суперника падає до `0`.

## 🧠 Формула атаки

Шкода приблизно розраховується за формулою:

```text
damage = attack + random_bonus - defense / 5
```

При цьому використовується випадкове значення, тому результат бою може відрізнятися навіть для схожих роботів.

## 🚀 Запуск

Переконайся, що встановлений Python 3.

Клонуй репозиторій:

```bash
git clone https://github.com/USERNAME/robot-arena.git
```

Перейди до папки:

```bash
cd robot-arena
```

Запусти гру:

```bash
python main.py
```
